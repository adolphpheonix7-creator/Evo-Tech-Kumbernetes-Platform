# Evo Tech Kubernetes Platform

## Production-Style Cloud & Platform Engineering Demonstration

A production-style cloud-native platform demonstrating modern DevOps and Platform Engineering practices using Docker, Kubernetes, Terraform, CI/CD, and Python.

This project is part of the **Evo Tech** engineering portfolio and demonstrates how an application can be containerized, infrastructure can be defined as code, and automated CI/CD can be used to validate changes.
